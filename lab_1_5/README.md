# Лабораторна робота 1.5 — Алгоритми пошуку

**Клас:** Student (студент)
**Поля:** прізвище, ім'я, група, стать, номер залікової книжки

## Рівні
* **level1.py** — інтерполяційний пошук серед чоловіків у впорядкованому масиві.
* **level2.py** — BST з вставкою у корінь через ротації (пошук за № залікової).
* **level3.py** — Splay Tree (zig/zig-zig/zig-zag операції) для амортизаційного балансування.

## Запуск
python level1.py
python level2.py
python level3.py

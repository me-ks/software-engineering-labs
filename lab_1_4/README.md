# Лабораторна робота 1.4 — Алгоритми сортування

**Структура даних:** Одновимірний масив
**Клас:** Student (студент)
**Поля:** прізвище, ім'я, група, номер студентського квитка

## Рівні
* **level1.py** — сортування Шелла з послідовністю Кнута. Ключ: група (↑).
* **level2.py** — сортування Шелла (стандартне n/2). Ключ: група (↑), квиток (↑).
* **level3.py** — висхідне сортування злиттям (Bottom-up Merge Sort).

## Запуск
python level1.py
python level2.py
python level3.py

# Лабораторна робота 1.2

**Тема:** Хеш-таблиця з відкритою адресацією
**Метод хешування:** Метод множення (Кнут)
**Клас:** Square (Квадрат)
**Ключ:** Площа квадрата

## Структура рівнів

* **Рівень 1:** Базова хеш-таблиця. При виникненні колізії елемент не додається.
* **Рівень 2:** Вирішення колізій методом квадратичного зондування.
* **Рівень 3:** Видалення елементів, периметр яких перевищує заданий поріг.

## Запуск

Для запуску всіх рівнів одночасно:
python index.py

Для запуску окремих рівнів:
python src/level1.py
python src/level2.py
python src/level3.py

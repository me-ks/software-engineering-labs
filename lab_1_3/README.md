# Лабораторна робота 1.3 — Бінарне дерево пошуку

**Структура даних:** Бінарне дерево пошуку (BST)
**Клас:** Student (студент)
**Ключ:** студентський квиток (унікальний)
**Обхід:** у ширину (BFS)

## Рівні

* **level1.py** — побудова BST та виведення всіх елементів через обхід у ширину.
* **level2.py** — пошук студентів-чоловіків 3-го курсу, що проживають у гуртожитку.
* **level3.py** — видалення знайдених студентів з дерева (листок, один нащадок, два нащадки).

## Запуск

python level1.py
python level2.py
python level3.py
